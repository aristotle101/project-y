## AS IS (ปัจจุบัน)

### BKK & Urban
- ลูกค้าที่สั่งซื้อสินค้า Hardline ได้ พื้นที่ต้องครอบคลุม Polygon Hardline และ Polygon Nextday หรือ Express, Pickup
- สาขาที่รับผิดชอบคำสั่งซื้อขึ้นอยู่กับพื้นที่ลูกค้า ตาม logic:
  - ถ้าพื้นที่มีสาขารับผิดชอบ nextday → สาขานั้นรับผิดชอบ ถ้าไม่รองรับ nextday
  - ถ้าพื้นที่รองรับ express → สาขานั้นรับผิดชอบ ถ้าไม่รองรับ express
  - ถ้าพื้นที่รองรับ pickup → สาขานั้นรับผิดชอบ

### UPC
- ลูกค้าที่สั่งซื้อ Hardline ได้ พื้นที่ต้องครอบคลุม Polygon Hardline และ Polygon Nextday
- สาขาที่รับผิดชอบคำสั่งซื้อมีแค่ 1 สาขา ต่อ 1 DC

## TO BE (เป้าหมาย)

สินค้าที่ถูก flag เป็น Hardline: ถ้ามี stock สาขาไหนและสินค้ารองรับการจัดส่งประเภทไหน ลูกค้าสามารถสั่งซื้อได้

| Shipping | Logic หาสาขา | ตัด stock | ราคาแสดง |
| :--- | :--- | :--- | :--- |
| **express** | Nearest; ถ้าลูกค้าเลือกสาขาเอง → ได้สาขาที่เลือก | สาขา Express | สาขา Express |
| **nextday** | สาขา Polygon Nextday | สาขา Nextday | สาขา Nextday |
| **pickup** | Nearest; ถ้าลูกค้าเลือก Pickup + เลือกสาขาเอง → ได้สาขาที่เลือก | สาขา Pickup | สาขา Pickup |
| **parcel** | สาขาตาม Config (บางนา — สาขาเดียวที่ส่ง parcel ได้) | สาขา Config | สาขา Config |
| **bulky** | Priority 1 Nextday → 2 Express → 3 Pickup | **DC** | สาขาที่สร้าง order |

> คำสั่งซื้อถูกสร้างลงสาขาตาม logic การหาสาขาของแต่ละ shipping

**Bulky — ตัวอย่างพฤติกรรม:**
- ลูกค้า A: พื้นที่ครอบคลุม Polygon Nextday + Polygon Hardline → ได้สาขา C, order ลงสาขา C, ตัด stock ที่ DC, เลือก Nextday/Pickup/Bulky ได้
- ลูกค้า B (เคสวัดหล่อ/ขอบเขต): พื้นที่ครอบคลุมแค่ Pickup + Polygon Hardline (อยู่นอกรัศมี Polygon Nextday จึงสั่ง Nextday ไม่ได้ แต่ยังสั่ง Hardline ได้เพราะอยู่ใน Polygon Hardline) → ได้สาขา C (Nearest), order ลงสาขา C, ตัด stock ที่ DC, เลือก Pickup/Bulky ได้

### ⚠️ การเปลี่ยนแปลงสำคัญ
- **เลิกใช้ `IS NON-HUB`**
- ใน Opal ยังไม่ต้องเอา "Hide IS non hub" ออก **แต่ใน Code ต้องไม่เช็ค is non hub**

## APPLY: Bangkok & Metropolitan & UPC

เปลี่ยน logic ใหม่ให้ใช้เหมือนกันหมดทั้ง BKK & Metropolitan และ UPC **แต่ BKK & Metropolitan ใช้ API ต่างกันกับ UPC**

- ลูกค้าสั่งซื้อ Hardline ได้ พื้นที่ต้องครอบคลุม Polygon Hardline และ Polygon Nextday **หรือ Express, Pickup**
- สาขาที่รับผิดชอบขึ้นกับพื้นที่ลูกค้า ตาม logic เดียวกับ AS IS (nextday → express → pickup)
- สาขาที่รับผิดชอบต้องมีสินค้าที่กำหนดเป็น Hardline และสาขานั้นต้องกำหนดเป็น Bulky → ลูกค้าเลือก express, nextday, pickup, bulky ได้
